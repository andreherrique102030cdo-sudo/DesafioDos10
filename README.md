
# Desafio dos 10

Jogo Android — versão 0.1.

## Mecânica atual
- Partidas de perguntas matemáticas.
- 10 segundos por pergunta.
- 4 alternativas.
- +100 pontos por acerto.
- Resposta errada ou tempo esgotado encerra a partida.
- Melhor pontuação salva no aparelho.
- Funciona offline.

## Gerar APK pelo GitHub
O projeto já contém o workflow `.github/workflows/build-apk.yml`.

Após enviar os arquivos para o GitHub:
1. Abra a aba **Actions**.
2. Entre em **Build APK**.
3. Execute o workflow, se necessário.
4. Quando terminar, abra a execução concluída.
5. Na seção **Artifacts**, baixe `DesafioDos10-debug`.
